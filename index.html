03Methodology

Version 0.1 · Fully public · Open pipeline

Normalization

metric_z = (x − median) / IQR

Each raw metric is robust-normalized against the current cohort of comparable-role leaders (all CMs). Role constraints — opposition vs. ruling, coalition vs. majority — are handled by comparing within role-classes, never across.

Composite

Effectiveness = Σ wᵢ · metric_zᵢ → rescaled 0–100

Weighted sum of the eight normalized metrics, rescaled so the cohort median is 50 and the observed range maps to roughly 10–90. No score is published for a leader with fewer than 5 of 8 metrics.

Data Sources

PRS · RBI · CAG · ECI · state budget docs

Only government-published or neutral-third-party data. Every number links to its source document; every score page shows all inputs so critics can attack the inputs, not just the output.
